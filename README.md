# MiniOS-Sim

A modular operating system simulator written in C11 for CEN 302 Operating Systems.

## Assigned Variants
- **Extra Scheduler:** MLFQ
- **Extra Synchronization Problem:** Readers-Writers
- **Extra Allocator:** Next Fit
- **Extra Page Replacement:** LFU

## Build
    make

## Run (First Run Example)
    ./minios sched a fcfs tests/first-run.txt
